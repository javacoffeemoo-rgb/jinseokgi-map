# 진석기시대 방문 장소 지도

유튜브 채널 **진석기시대**(낚시·자급자족 요리 크리에이터)가 다녀간 장소를 지도에 정리한 페이지입니다.

## 데이터 출처 및 방법

1. 채널 영상 **471개**(2019.02 ~ 2026.10) 목록 수집
2. 각 영상의 **제목 · 태그(유튜브 숨김 키워드) · 설명·해시태그** 수집
3. 전국 행정구역·섬·항구 목록과 대조해 장소 추출
4. [OpenStreetMap Nominatim](https://nominatim.org/)으로 좌표 변환

## 결과

- 표시 지점 **110곳** — 시·군 44 / 섬 29 / 항구·포구 22 / 강·호수·산 9 / 해외 6
- 위치가 확인된 영상 **201개**

## 페이지 기능

- 지도 위 점 = 장소 (점 크기 = 관련 영상 수)
- 장소 클릭 → 해당 영상 제목과 유튜브 링크, 근거 뱃지(제목/태그/설명) 표시
- **근거 필터**: 제목 / 태그 / 설명 각각 켜고 끄기
- **분류 필터**: 시·군, 섬, 항구, 강·산, 해외
- 밀집 지역(통영·거제 등)은 자동 클러스터링

## 참고

- 좌표는 **지역·섬 단위 중심점**입니다(예: "통영" = 통영시 중심). 정확한 낚시 포인트 단위는 아닙니다.
- 지도 타일은 OpenStreetMap, 지도 라이브러리는 Leaflet CDN을 사용하므로 **인터넷 연결이 필요**합니다.
- 영상 원본과 무관한 비공식 팬 페이지입니다. 영상 저작권은 원저작자에게 있습니다.
